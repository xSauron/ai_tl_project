# Claude Code

The rules in `AGENTS.md` apply in full, including the mandatory `.ai/` metadata structure:

- Specs: `.ai/specs/YYYY-MM-DD-slug.md` (move to `implemented/` when shipped, `archive/` when abandoned).
- Runs: every autonomous run logs to `.ai/runs/YYYY-MM-DD-slug.md`.
- Lessons: read `.ai/lessons.md` before starting; append findings after bug fixes and runs (details in `.ai/lessons/`).
