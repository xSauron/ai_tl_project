# Runs

Logs of autonomous AI runs. Every run writes exactly one log.

- File naming: `YYYY-MM-DD-slug.md` (date = run start date, lowercase kebab-case slug).
- Suggested contents: goal, related spec, plan/steps, commands and decisions, results, open issues, follow-ups.
- Lessons discovered during a run go to `.ai/lessons.md`, not only here.
