# Specs

Specifications for Spec-Driven Development (SDD). Write the spec first, then implement it.

- File naming: `YYYY-MM-DD-slug.md` (date = creation date, lowercase kebab-case slug).
- `.ai/specs/` — active specs (draft / approved / in progress).
- `.ai/specs/implemented/` — specs whose implementation has shipped. Move the file here (keep its name).
- `.ai/specs/archive/` — abandoned, superseded, or obsolete specs. Move the file here and note why at the top.
